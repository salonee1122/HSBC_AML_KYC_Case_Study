# HSBC AML & KYC Case Study – 2012

This project explains HSBC's 2012 US AML and sanctions case, highlighting weaknesses in anti-money laundering controls and customer due diligence.

### Key Topics
- AML, KYC and money laundering stages
- Case details and regulatory violations
- Transaction monitoring failures
- Fines and penalties (approximately $1.9 billion)
- Red flags and key compliance lessons
